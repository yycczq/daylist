# 今日清单

一个用 HTML、CSS 和原生 JavaScript 写成的每日待办清单。添加任务、标记完成、筛选和删除都在浏览器里完成，数据保存在当前设备的 `localStorage`。

## 运行

不需要安装依赖。用浏览器打开 `index.html` 即可，也可以用 VS Code 的 Live Server。

## 这个项目适合练什么

- HTML 表单、按钮、列表和无障碍标签
- CSS 布局、颜色变量、手机适配和键盘焦点
- JavaScript 事件、数组、对象和 DOM 更新
- 用 `localStorage` 保存和读取 JSON 数据
- 把添加、完成、删除、筛选分别拆成小函数

## 文件

| 文件 | 内容 |
| --- | --- |
| `index.html` | 页面结构和表单 |
| `style.css` | 桌面与手机样式 |
| `app.js` | 添加任务、渲染、筛选与本地保存 |
| `LICENSE.md` | 原项目 MIT 许可证 |
